---
title: "Set Password (Invitation)"
description: "Halaman set password untuk user yang diundang admin lewat invitation link"
---

Halaman ini digunakan oleh user yang menerima [Invitation](/admin-panel/users/invitations) dari admin. Bersifat **public** (tidak perlu login) dan diakses lewat token unik.

## Route

| Route Name | Path | Component |
| --- | --- | --- |
| `invitation.set-password` | `/invitation/{token}` | `App\Livewire\SetPassword` |

<Info>
  Route ini **tidak** ter-localize — path sama di semua bahasa.
</Info>

## Field

| Field | Tipe | Validasi |
| --- | --- | --- |
| `password` | Password | `required`, `min:8`, `same:passwordConfirmation` |
| `passwordConfirmation` | Password | Harus sama dengan `password` |

## Flow

<Steps>
  <Step title="User klik link di email">
    Link `/invitation/{token}` dari email invitation admin.
  </Step>
  <Step title="Token divalidasi">
    Livewire component cek `Invitation::where('token', $token)->first()->isValid()`. Jika token tidak valid atau expired → return 404.
  </Step>
  <Step title="User isi password">
    Isi password dan konfirmasi.
  </Step>
  <Step title="Submit">
    User existing (email match) di-update: `password` di-hash, `is_admin = true`. Invitation ditandai `accepted_at = now()`.
  </Step>
  <Step title="Auto-login ke admin panel">
    User langsung login dan redirect ke `filament.admin.pages.dashboard` (`/admin`).
  </Step>
</Steps>

## Layout

Menggunakan `layouts.guest` (bukan layout customer). Tampilan minimal tanpa header/footer utama.

<Warning>
  Setelah `accepted_at` di-set, token tidak valid lagi. User yang sudah accept harus login lewat halaman login normal.
</Warning>
