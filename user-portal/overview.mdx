## Struktur URL (Localized)

Semua halaman frontend menggunakan URL yang ditranslate. Contoh dengan default locale `en` dan alternate `id`:

| Route Name | EN | ID |
| --- | --- | --- |
| `home` | `/` | `/id` |
| `products.index` | `/products` | `/id/produk` |
| `products.show` | `/products/{slug}` | `/id/produk/{slug}` |
| `checkout.create` | `/checkout/{product}` | `/id/checkout/{product}` |
| `blog.index` | `/blog` | `/id/blog` |
| `blog.show` | `/blog/{slug}` | `/id/blog/{slug}` |
| `pages.show` | `/{slug}` | `/id/{slug}` |
| `customer.dashboard` | `/dashboard` | `/id/dashboard` |
| `customer.downloads` | `/downloads` | `/id/downloads` |
| `customer.profile` | `/profile` | `/id/profile` |

URL segment per locale diatur di [Multi-language](/features/multi-language).
