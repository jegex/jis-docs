Halaman ini menampilkan semua file digital yang bisa didownload oleh pelanggan berdasarkan order yang sudah `paid`.

## Route

| Route Name | Path (EN) | Path (ID) | Component | Middleware |
| --- | --- | --- | --- | --- |
| `customer.downloads` | `/downloads` | `/id/downloads` | `App\Livewire\CustomerDownloads` | `auth`, `verified` |

## Route Download File

| Route Name | Path | Controller | Middleware |
| --- | --- | --- | --- |
| `payment.download` | `/download/{order:order_number}/{product}` | `App\Http\Controllers\Payment\DownloadController@download` | `auth` |

<Info>
  Route `/download/{order}/{product}` **tidak** ter-localize — URL sama di semua bahasa.
</Info>

## Konten

Menampilkan **order yang sudah paid** dengan produknya:

```php
Order::where('user_id', auth()->id())
    ->paid()
    ->with('items.product', 'items.product.media')
    ->latest('paid_at')
    ->get();
```

### Per Order

- Tanggal paid (`paid_at`)
- Order number
- List produk yang dibeli dengan:
  - Cover image
  - Nama produk
  - Tombol **Download** (jika tersedia)
  - Badge **Preorder** (jika produk belum dirilis)
  - Info tanggal release untuk produk preorder

## Preorder Products

Untuk produk dengan status preorder:

- Tombol **Download** tidak aktif sampai produk di-release
- Badge **Preorder** ditampilkan dengan tanggal release
- Pesan "Download will be available after release" muncul
- Setelah release, tombol **Download** akan aktif dan user bisa mendownload file

<Info>
  Admin bisa melakukan release produk secara manual via `php artisan preorders:release` atau sistem akan otomatis me-release saat tanggal release tiba.
</Info>

## Cara Kerja Download

<Steps>
  <Step title="User klik Download">
    Livewire method `getDownloadUrl($orderId, $productId)` dipanggil.
  </Step>
  <Step title="Validasi ownership">
    Method cek `Order` milik `auth()->id()` dan sudah `paid`. Jika tidak match, return `#`.
  </Step>
  <Step title="Generate URL">
    `DownloadService::generateDownloadUrl($order, $product)` bikin URL dengan signed token / expiry.
  </Step>
  <Step title="User di-redirect ke download route">
    `/download/{order_number}/{product}` di-hit. Controller stream file dari disk `local`.
  </Step>
</Steps>

## Keamanan

- Route butuh `auth` middleware.
- Controller memvalidasi **dua hal**: (1) signed URL signature valid atau user adalah pemilik order, dan (2) order memenuhi syarat download via `canDownload()`.
- Jika signature tidak valid **dan** user bukan pemilik → `401 Unauthorized`.
- Jika signature valid atau user pemilik, tetapi `canDownload()` gagal (status bukan `paid`, produk belum dirilis, dll) → `403 Forbidden`.
- File disimpan di disk `local` (bukan `public`), tidak bisa diakses langsung lewat URL.

<Warning>
  Signed download URL dapat diakses tanpa login selama signature masih valid (24 jam). Untuk keamanan tambahan, gunakan signed URL yang pendek atau tambahkan validasi ownership di level aplikasi.
</Warning>

<Tip>
  Setelah pembayaran sukses, sistem otomatis kirim email dengan template `download_link` yang berisi shortcut ke halaman ini.
</Tip>
