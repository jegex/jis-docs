Variable environment di-load dari file `.env` di root project. Salin dari `.env.example` saat setup:

```bash
cp .env.example .env
php artisan key:generate
```

## Application

| Variable | Default | Deskripsi |
| --- | --- | --- |
| `APP_NAME` | `Laravel` | Nama aplikasi. Ditampilkan di email dan meta tag. |
| `APP_ENV` | `local` | Environment: `local`, `staging`, `production`. |
| `APP_KEY` | (kosong) | Encryption key. Generate dengan `php artisan key:generate`. |
| `APP_DEBUG` | `false` | Tampilkan stack trace saat error. **Selalu `false` di production**. |
| `APP_URL` | `http://localhost` | URL dasar aplikasi. Dipakai untuk generate absolute URL. |
| `APP_LOCALE` | `en` | Locale default. |
| `APP_FALLBACK_LOCALE` | `en` | Fallback locale jika translation tidak ada. |
| `APP_FAKER_LOCALE` | `en_US` | Locale Faker untuk seeder / factory. |
| `APP_MAINTENANCE_DRIVER` | `file` | Driver maintenance mode. |
| `BCRYPT_ROUNDS` | `12` | Cost bcrypt untuk hashing password. |

## Logging

| Variable | Default | Deskripsi |
| --- | --- | --- |
| `LOG_CHANNEL` | `stack` | Channel log default. |
| `LOG_STACK` | `single` | Stack channels. |
| `LOG_DEPRECATIONS_CHANNEL` | `null` | Channel untuk deprecation warnings. |
| `LOG_LEVEL` | `debug` | Level minimum yang di-log. Di production biasanya `warning` / `error`. |

## Database

| Variable | Default | Deskripsi |
| --- | --- | --- |
| `DB_CONNECTION` | `mysql` | Driver DB: `mysql`, `pgsql`, `sqlite`. |
| `DB_HOST` | `127.0.0.1` | Host DB server. |
| `DB_PORT` | `3306` | Port DB (MySQL: 3306, Postgres: 5432). |
| `DB_DATABASE` | `jis` | Nama database. |
| `DB_USERNAME` | `root` | Username DB. |
| `DB_PASSWORD` | (kosong) | Password DB. |

Detail lihat [Database Configuration](/configuration/database).

## Session & Cache

| Variable | Default | Deskripsi |
| --- | --- | --- |
| `SESSION_DRIVER` | `database` | Driver session: `database`, `redis`, `file`. |
| `SESSION_LIFETIME` | `120` | Umur session dalam menit. |
| `SESSION_ENCRYPT` | `false` | Enkripsi session payload. |
| `SESSION_PATH` | `/` | Cookie path. |
| `SESSION_DOMAIN` | `null` | Cookie domain (untuk subdomain sharing). |
| `CACHE_STORE` | `database` | Driver cache: `database`, `redis`, `file`, `array`. |

## Queue

| Variable | Default | Deskripsi |
| --- | --- | --- |
| `QUEUE_CONNECTION` | `database` | Driver queue: `database`, `redis`, `sync`. |
| `BROADCAST_CONNECTION` | `log` | Driver broadcasting. |

<Warning>
  Jangan pakai `QUEUE_CONNECTION=sync` di production. Email dan job berat akan block request.
</Warning>

## Filesystem

| Variable | Default | Deskripsi |
| --- | --- | --- |
| `FILESYSTEM_DISK` | `local` | Disk default. **File produk digital selalu di disk `local`** (bukan public). |

## Vite (Frontend Build)

| Variable | Default | Deskripsi |
| --- | --- | --- |
| `VITE_APP_NAME` | `${APP_NAME}` | Nama app yang diekspos ke frontend JS. |

<Tip>
  Variable dengan prefix `VITE_` diekspos ke browser. Jangan simpan secret di sini.
</Tip>

## Security Checklist Production

<Steps>
  <Step title="APP_DEBUG=false">
    Cegah stack trace bocor ke user.
  </Step>
  <Step title="APP_KEY di-generate">
    `php artisan key:generate` sekali saat deploy pertama.
  </Step>
  <Step title="MIDTRANS_IS_PRODUCTION=true">
    Pindah dari sandbox ke production key.
  </Step>
  <Step title="LOG_LEVEL=warning">
    Kurangi noise log di production.
  </Step>
  <Step title="QUEUE_CONNECTION=database (atau redis)">
    Bukan `sync` supaya email tidak block request.
  </Step>
  <Step title="MAIL_MAILER=smtp">
    Bukan `log`. Setup provider seperti Mailgun/Postmark.
  </Step>
</Steps>
