Semua enum di JIS berada di namespace `App\Enums`. Enum yang diimplement `HasColor` / `HasLabel` otomatis punya badge di Filament.

## OrderStatus

**Namespace:** `App\Enums\OrderStatus` · **Implements:** `HasColor`, `HasLabel`

| Case | Value | Color | Deskripsi |
| --- | --- | --- | --- |
| `Pending` | `pending` | warning | Order baru dibuat, belum ada aksi pembayaran. |
| `CreatingPayment` | `creating_payment` | gray | Sistem sedang membuat transaction Midtrans. |
| `AwaitingPayment` | `awaiting_payment` | warning | Snap popup sudah muncul, menunggu pelanggan bayar. |
| `Paid` | `paid` | success | Pembayaran sukses, file digital bisa didownload. |
| `Failed` | `failed` | danger | Pembayaran gagal (deny/cancel/failure). |
| `Expired` | `expired` | gray | Order kadaluwarsa (tidak dibayar dalam batas waktu). |
| `Refunded` | `refunded` | info | Order di-refund. |

**Query scope:** `Order::paid()` filter status = `Paid`.

## EmailTemplateType

**Namespace:** `App\Enums\EmailTemplateType`

| Case | Value | Kapan Dikirim |
| --- | --- | --- |

| `OrderConfirmation` | `order_confirmation` | Setelah pembayaran sukses (`OrderStatus::Paid`). |

## MenuItemType (Package)

**Namespace:** `Biostate\FilamentMenuBuilder\Enums\MenuItemType`
