Admin panel JIS dibangun dengan **Filament 5** dan bisa diakses di `/admin`.

```text
https://domainmu.com/admin
```

## Login Admin

User dengan role admin bisa login menggunakan email dan password yang sudah didaftarkan. User admin default dibuat lewat seeder saat `php artisan migrate --seed` dijalankan.

<Warning>
  Ganti password admin default segera setelah instalasi selesai.
</Warning>

## Dashboard Widgets

Halaman utama admin menampilkan beberapa widget:

| Widget | Fungsi |
| --- | --- |
| **Sales Overview** | Ringkasan penjualan (total revenue, jumlah order, average order value). |
| **Order Stats Overview** | Statistik order per status (pending, paid, cancelled). |
| **Revenue Chart** | Grafik revenue per periode. |
| **Orders By Status Chart** | Distribusi order berdasarkan status. |
| **Latest Orders** | Daftar order terbaru dengan quick action. |
