**JIS (CMS Shop Digital)** adalah aplikasi web e-commerce multi-bahasa (Indonesia & Inggris) untuk penjualan produk digital seperti dokumen, desain, blueprint, dan file teknis lainnya.

Dibangun dengan **Laravel 13**, **Filament 5** (admin panel), dan **Livewire 4** (frontend interaktif).

## Tech Stack

| Layer | Teknologi |
| --- | --- |
| Backend | PHP 8.4, Laravel 13 |
| Admin Panel | Filament 5 |
| Frontend | Livewire 4, Tailwind CSS 4, Alpine.js |
| Database | MySQL 8.0\+ / MariaDB 10.6\+ |
| Payment | Midtrans (aktif), Stripe & Xendit (stub) |
| Auth | Laravel Fortify, Laravel Socialite (Google) |
| Testing | Pest 4, PHPUnit 12 |
