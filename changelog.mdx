## v1.5.1

**Tanggal:** 27 Agustus 2026

### Bug Fixes

- Perbaikan email preorder: sembunyikan tombol download untuk preorder, tampilkan info kapan download tersedia
- Tambah template email `PreorderRelease` (bilingual en/id)
- Schedule `preorders:release` otomatis tiap jam
- Perbaiki `is_published` toggle selalu reset ke false saat edit produk/post/page

### Improvements

- Tambah tombol filter "Released" di halaman katalog produk
- Customer downloads tampilkan badge "Pending Release" untuk preorder
- Release preorder sekarang handle semua item dalam order (bukan hanya item pertama)
- Update variabel email template info panel di admin

### Maintenance

- Hapus `is_published` dari `$hidden` di model Product, Post, Page

## v1.5.0

**Tanggal:** 24 Agustus 2026

### New Features

- **Auto Invoice PDF**: Invoice PDF otomatis di-generate setelah pembayaran, terlampir di email konfirmasi
- **Product Preorder**: Produk bisa dibeli sebelum release date, download saat ready
- **Email Logs**: Audit trail semua email yang terkirim

### Improvements

- Tombol **Resend Confirmation** bisa diklik berulang kali
- Email dedup via cache lock mencegah duplicate email
- Badge "Preorder" di katalog dan detail produk
- Filter produk berdasarkan status (Regular/Preorder/Released)

### Bug Fixes

- Perbaikan SEO fallback default og\_default
- Perbaikan gate untuk super\_admin
- Perbaikan style CSS button card
