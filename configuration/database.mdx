JIS menggunakan MySQL 8.0\+ atau MariaDB 10.6\+ sebagai database utama. Semua konfigurasi diatur melalui file `.env`.

## Environment Variables

Buka file `.env` dan isi bagian database:

```ini
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=jis
DB_USERNAME=root
DB_PASSWORD=
```

| Variable | Keterangan |
| --- | --- |
| `DB_CONNECTION` | Driver database. Biarkan `mysql`. |
| `DB_HOST` | Host database. Biasanya `127.0.0.1` untuk lokal. |
| `DB_PORT` | Port database. Default MySQL: `3306`. |
| `DB_DATABASE` | Nama database yang sudah dibuat. |
| `DB_USERNAME` | Username database. |
| `DB_PASSWORD` | Password database. Kosongkan jika tidak ada. |

## Setup Database di cPanel

<Steps>
  <Step title="Buka MySQL Databases">
    Login ke cPanel, cari menu **MySQL Databases**.
  </Step>
  <Step title="Buat database baru">
    Isi nama database (contoh: `cms_shop_db`), lalu klik **Create Database**.
  </Step>
  <Step title="Buat user database">
    Scroll ke bagian **MySQL Users**, isi username dan password, klik **Create User**.
  </Step>
  <Step title="Attach user ke database">
    Di bagian **Add User to Database**, pilih user dan database, lalu beri **ALL PRIVILEGES**.
  </Step>
  <Step title="Update .env">
    Isi `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` sesuai kredensial yang baru dibuat.

    <Warning>
      Nama database di cPanel biasanya diawali prefix username, misalnya `cpaneluser_cms_shop_db`. Gunakan nama lengkapnya.
    </Warning>
  </Step>
</Steps>

## Migrasi Database

Setelah `.env` terisi, jalankan migrasi untuk membuat tabel dan seed data awal:

```bash
php artisan migrate --seed
```

Jika ingin reset ulang database (menghapus semua data), gunakan:

```bash
php artisan migrate:fresh --seed
```

<Warning>
  `migrate:fresh` akan menghapus semua tabel dan datanya. Jangan gunakan di production.
</Warning>
