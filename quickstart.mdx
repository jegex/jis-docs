Panduan ini membawa Anda dari clone repository sampai aplikasi berjalan di `http://localhost:8000`.

## Prerequisites

Pastikan komponen berikut sudah terpasang di komputer Anda:

| Komponen | Versi Minimal |
| --- | --- |
| PHP | 8.4 |
| Composer | 2.x |
| MySQL | 8.0\+ / MariaDB 10.6\+ |
| Node.js | 20\+ |
| NPM | 10\+ |

### PHP Extensions

Pastikan extension berikut aktif:

```text
BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL,
PDO, MySQL, Tokenizer, XML, GD, Exif, Zip
```

## Setup Lokal

<Steps>
  <Step title="Clone repository">
    ```bash
    git clone https://github.com/jegex/jis.git cms-shop
    cd cms-shop
    ```
  </Step>
  <Step title="Install dependency PHP">
    ```bash
    composer install
    ```
  </Step>
  <Step title="Buat file .env">
    ```bash
    cp .env.example .env
    php artisan key:generate
    ```

    Edit `.env` dan sesuaikan konfigurasi database. Lihat [Konfigurasi Database](/configuration/database) untuk detail.
  </Step>
  <Step title="Migrasi database + seed data">
    ```bash
    php artisan migrate --seed
    ```
  </Step>
  <Step title="Buat symlink storage">
    ```bash
    php artisan storage:link
    ```
  </Step>
  <Step title="Install & build frontend">
    ```bash
    npm install
    npm run build
    ```
  </Step>
  <Step title="Jalankan development server">
    ```bash
    composer run dev
    ```

    Perintah ini menjalankan 4 service sekaligus: web server, queue worker, log viewer, dan Vite dev server.
  </Step>
</Steps>

Akses aplikasi di browser: [http://localhost:8000](http://localhost:8000)

Akses admin panel di: [http://localhost:8000/login](http://localhost:8000/login)
